Zadanie 6.
Sformułuj treść zadania, którego rozwiązaniem jest poniższa instrukcja SQL:

SELECT IDPojazdu,COUNT(*)
FROM kursy
GROUP BY IDPojazdu
HAVING COUNT(*) = 
   (SELECT AVG(liczk)
    FROM (SELECT COUNT(*) AS liczk 
          FROM kursy 
          GROUP BY IDPojazdu) )
